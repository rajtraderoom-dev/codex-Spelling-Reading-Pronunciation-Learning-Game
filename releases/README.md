# Install Word Garden

Download **WordGarden-debug.apk** to an Android 7.0+ phone and open the file to install it. Android may ask you to allow this browser/file manager to install this app. This is a debug-signed testing build, not a Play Store release.

Open the grown-up corner in the app to check the offline English voice and optionally enable the on-device microphone. Android 12+ with a compatible offline recognizer is required for speech recognition; all devices have listen-and-tap practice.

Build/run guide: [Android README](../android/README.md). Implementation review: [prompt review](../docs/PROMPT-REVIEW.md). Check results: [validation](../docs/ANDROID-VALIDATION.md).

Verify the download against `SHA256SUMS`. From the repository root:

```sh
sha256sum -c releases/SHA256SUMS
```
